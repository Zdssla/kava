# KAVA — концепт сайта вымышленной кофейни

[Посмотреть сайт](https://zdssla.github.io/kava/)

Одностраничный сайт на HTML, CSS и JavaScript с адаптивной вёрсткой, мобильным меню с клавиатурным управлением, локальными шрифтами и фотографиями в WebP.

## Запуск

Из папки проекта выполните:

```bash
python -m http.server 8000
```

Откройте в браузере http://localhost:8000.
